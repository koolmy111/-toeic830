# TOEIC 830 Coach FINAL

最终版 90 天 TOEIC 830 备考系统。

## 核心
- Day 1-90 分阶段路线
- 每日新词 + SRS 复习
- Part 2
- Part 3/4 训练
- Part 5/6
- Part 7
- Listening 真实训练时间记录
- Mini Mock 计时模式
- 错题记录
- XP / 连续学习 / 完成天数
- 分项训练量与正确率
- Mock 历史趋势
- JSON 进度导出
- 手机端响应式界面

## 使用
解压后打开 index.html。

注意：题目为训练型原创题，不是官方 TOEIC 真题；Listening 模块记录你使用正版/公开音频的训练时间，不内置受版权保护的 TOEIC 音频。
